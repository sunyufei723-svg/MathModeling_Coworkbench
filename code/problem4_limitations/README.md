# problem4_limitations —— Q4「干物质 28.02% 漂移」局限性分析的诊断代码

本文件夹收录支撑 [`discussion/limitations_fix_analysis_by_A.md`](../../discussion/limitations_fix_analysis_by_A.md)
§一（28.02% 干物质漂移根因）与 §二（汽化潜热）分析的**可复现诊断脚本**。
它们由早先 gitignore 的 `附件/_scratch_*.py` 中**筛选出支撑当前（已更正）结论的干净脚本**提升而来，
改为可移植路径、统一 UTF-8 输出，作为仓库正式产物长期留存。

## 一句话结论（这些脚本共同证明的）

Q4 报告的「干物质指标相对变幅 28.02%」**不是数值错误、不是拟合错误、不是含水率算错、也不是忽略潜热造成的**，
而是**两条题给关系（附录4 密度律 ρ(C) 与附件2 半径轨迹 R(t)）在数学上不相容**：
干物质闭合要求 ρ_s = ρ_s0·(R0/R)²，而附录4 的干基密度 ρ_s(C)=90+670/(1+C) 上确界仅 760 kg/m³（C=0），
自 R(t) 跌破临界半径 R_c=1.211203 cm 起（附件2 自 t=19.5 h、106/145 点）闭合**物理上不可达**，
终点 t\* 处硬上界 κ(t\*)≤0.9816（缺口≥1.84% 永不闭合）。计入潜热只会**放大**缺口（见下）。

## 运行方式

```powershell
# 仓库根目录下（脚本用 __file__ 定位仓库根，从任意 cwd 运行均可）
python code/problem4_limitations/upper_bound_proof.py
```

- **依赖**：与 [`code/problem4_fvm_bdf/`](../problem4_fvm_bdf) 相同的 Python 环境（numpy / scipy / pandas / openpyxl）；
  运行时只读 import 该求解器包，**不修改 `code/`、`results/` 下任何文件**。
- **数据**：需要 `附件/附件1.xlsx`、`附件/附件2.xlsx` 在位（题目原始附件，gitignore，不入库）。
- **编码**：脚本已强制 stdout/stderr 为 UTF-8（含 `⇒ κ ρ ⟨⟩` 等字符）。在 Windows GBK 控制台直接看会有乱码，
  属显示层假象；请 `chcp 65001` 切 UTF-8 控制台，或重定向到文件后用 UTF-8 编辑器查看，输出字节本身正确。
- 单脚本耗时约 15 s–2 min（N=401 的 BDF 求解；`latent_heat_effect.py` 扫 4 个 ΔT 最慢）。
