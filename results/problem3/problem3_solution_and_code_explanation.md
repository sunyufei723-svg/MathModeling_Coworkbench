# A题问题三解决思路与代码解析

## 1. 问题三要回答什么

问题三要求确定药材在给定烘干环境下的烘干终止时间。终止条件不是平均含水量低于 0.15 kg/kg，而是药材圆柱横截面内每一个径向位置的水分浓度都低于 0.15 kg/kg。

因此计算时需要持续追踪从药材中心到外表面的水分浓度分布，直到最大水分浓度也低于 0.15 kg/kg。通常中心位置最慢，所以终止时间基本由中心点决定。

## 2. 模型假设

1. 药材仍视为半径 2 cm、长度 25 cm 的圆柱体，问题三不考虑半径收缩。
2. 由于题目输出按“到药材中心的距离”给出，问题三采用径向一维模型，半径方向网格间距为 0.1 cm。
3. 环境温度和环境水分浓度来自附件1；附件1只给到 4 h，之后按最后一个环境值保持不变。
4. 温度场和水分场耦合计算：温度影响扩散系数，水分浓度影响密度、比热、热导率和扩散系数。
5. 终止判据采用全截面判据：`max(C(r,t)) < 0.15`。

## 3. 关键公式

物性参数沿用问题二使用的附件三经验公式：

```text
rho(C) = 650 + 128C
Cp(C) = 1450 + 2736*C/(1+C)
k(C) = 0.21 + 0.38*C/(1+C)
D(C,T) = 2.4e-3 * exp(-0.45/C) * exp(-3850/TK)
TK = T + 273.15
```

这里必须注意扩散系数第一项是 `exp(-0.45/C)`，是除以 C，不是乘以 C。

## 4. 数值算法

代码采用有限差分离散径向圆柱扩散方程。

每个时间步内部做 Picard 迭代：

1. 先用上一时刻的温度和水分作为预测值。
2. 根据预测水分更新密度、比热、热导率。
3. 求解温度隐式差分方程。
4. 根据新的温度和预测水分更新扩散系数。
5. 求解水分隐式差分方程。
6. 若温度和水分的变化都小于容差，则该时间步收敛；否则继续迭代。

这样做比“上一时刻温度直接代入下一时刻水分扩散”的滞后耦合更稳，也更符合问题二复核后采用的处理。

## 5. 输出结果

本次计算得到：

```text
烘干终止时间 = 198210 s = 55.0583 h
```

耦合迭代收敛统计：全部 **19821/19821** 时间步收敛，单步最大 Picard 迭代 **4** 次（上限 8、容差 1e-8）；后期虽因 D 随 C 减小而变刚性，但未出现不收敛。终止判据在求解器内部未四舍五入的全精度数组上判定，输出四舍五入到 4 位小数只影响显示，不影响 t_end。

## 6. 代码文件说明

`code/problem3/solver.py`

- 定义物性公式、径向隐式差分求解器、耦合迭代和终止判据。
- `moisture_diffusivity()` 中使用正确公式 `exp(-0.45 / C)` 和开尔文温度。
- `solve_problem3()` 按时间推进，直到全截面水分浓度低于 0.15。

`code/problem3/run_problem3.py`

- 读取附件1环境数据。
- 调用求解器计算终止时间。
- 生成 `result3.xlsx` 和论文用表格。
- 完整 Excel 与论文表格均按题目要求**保留 4 位小数**输出；终止判据在求解器内部的全精度数组上判定（`solver.py` 的 `drying_complete`），仅对导出结果四舍五入，不影响 t_end。

`code/problem3/test_solver.py`

- 检查附件1外推策略。
- 检查扩散系数公式是否写成除以 C。
- 检查终止条件是否是全截面低于阈值。
- 检查求解器能在简单场景下正确停止并收敛。

## 7. 边界敏感性与国奖级补强要求

第三问的核心风险不在求解器，而在 4 h 之后的烘房边界外推。附件1只给到 4 h，本实现采用 `EnvironmentSeries` 的末值保持策略，即：

```text
T_env(t>4h) = T_env(4h)
C_env(t>4h) = C_env(4h)
```

由于烘干终止时间达到 55.0583 h，绝大部分积分时间都处在外推边界下，因此该假设会直接影响 `t_end`。论文中不能把 55.0583 h 写成脱离边界假设的绝对真值，而应写成“在附件1末值恒定外推假设下的终止时间”。

建议补做边界敏感性分析，至少围绕 `T_env` 和 `C_env` 两个末值扰动：

| 敏感性项 | 推荐设置 | 输出 |
| --- | --- | --- |
| 温度末值扰动 | `T_env(>4h) ± 2 °C` | `t_end` 变化量与相对变化率 |
| 环境水分末值扰动 | `C_env(>4h) ± 10%` | `t_end` 变化量与相对变化率 |
| 联合保守情形 | 低温 + 高环境水分 | 最慢烘干时间 |
| 联合乐观情形 | 高温 + 低环境水分 | 最快烘干时间 |

如果没有原始附件文件，不能伪造敏感性数值；至少应在正文“模型假设/误差分析”中明确该边界假设，并把 `T_env`、`C_env` 的末值外推列为主要不确定性来源。国奖级论文最好给出一张敏感性表，说明结论对边界外推的稳健性。
