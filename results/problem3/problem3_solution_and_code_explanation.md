# A题问题三解决思路与代码解析

## 1. 问题三要回答什么

问题三要求确定药材在给定烘干环境下的烘干终止时间。终止条件不是平均含水量低于 0.15 kg/kg，而是药材圆柱横截面内每一个径向位置的水分浓度都低于 0.15 kg/kg。

因此计算时需要持续追踪从药材中心到外表面的水分浓度分布，直到最大水分浓度也低于 0.15 kg/kg。通常中心位置最慢，所以终止时间基本由中心点决定。

## 2. 模型假设

1. 药材仍视为半径 2 cm、长度 25 cm 的圆柱体，问题三不考虑半径收缩。
2. 由于题目输出按“到药材中心的距离”给出，问题三采用径向一维模型，半径方向网格间距为 0.1 cm。
3. 环境温度和环境水分浓度来自附件1；附件1只给到 4 h，之后按最后一个环境值保持不变。
4. 温度场和水分场耦合计算：温度影响扩散系数，水分浓度影响密度、比热、热导率和扩散系数。
5. 终止判据采用全截面判据：`max(C(r,t)) < 0.15`。

## 3. 关键公式

物性参数沿用问题二使用的附件三经验公式：

```text
rho(C) = 850 + 280C
Cp(C) = 1200 + 2500C
k(C) = 0.18 + 0.22C/(1+C)
D(C,T) = 2.4e-3 * exp(-0.45/C) * exp(-3850/TK)
TK = T + 273.15
```

这里必须注意扩散系数第一项是 `exp(-0.45/C)`，是除以 C，不是乘以 C。

## 4. 数值算法

代码采用有限差分离散径向圆柱扩散方程。

每个时间步内部做 Picard 迭代：

1. 先用上一时刻的温度和水分作为预测值。
2. 根据预测水分更新密度、比热、热导率。
3. 求解温度隐式差分方程。
4. 根据新的温度和预测水分更新扩散系数。
5. 求解水分隐式差分方程。
6. 若温度和水分的变化都小于容差，则该时间步收敛；否则继续迭代。

这样做比“上一时刻温度直接代入下一时刻水分扩散”的滞后耦合更稳，也更符合问题二复核后采用的处理。

## 6. 代码文件说明

`code/problem3/solver.py`

- 定义物性公式、径向隐式差分求解器、耦合迭代和终止判据。
- `moisture_diffusivity()` 中使用正确公式 `exp(-0.45 / C)` 和开尔文温度。
- `solve_problem3()` 按时间推进，直到全截面水分浓度低于 0.15。

`code/problem3/run_problem3.py`

- 读取附件1环境数据。
- 调用求解器计算终止时间。
- 生成 `result3.xlsx` 和论文用表格。
- 完整 Excel 保留原始计算精度，避免四舍五入影响终止判据判断。

`code/problem3/test_solver.py`

- 检查附件1外推策略。
- 检查扩散系数公式是否写成除以 C。
- 检查终止条件是否是全截面低于阈值。
- 检查求解器能在简单场景下正确停止并收敛。
