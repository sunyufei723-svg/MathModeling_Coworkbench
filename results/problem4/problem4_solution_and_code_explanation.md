## 2. 移动边界处理——Landau 前置固定（front-fixing）+ 物质坐标

引入 ξ = r/R(t) ∈ [0,1]，把随时间收缩的物理域 r∈[0,R(t)] 映射到**固定计算域** ξ∈[0,1]。

**主口径取「物质型（无对流项）」**，依据：C 是**干基含水率**（kg 水/kg 干物质，物质属性），干基质量守恒（假设 G2），收缩为均匀缩放 ⇒ ξ 即**物质坐标**。对水守恒式作物质导数推导（ρ_dry·DC/Dt = −∇·J_w，J_w = −ρ_dry·D·∇C，DC/Dt = ∂C/∂t|_ξ），得 ξ 系方程**不含对流项**：

```
∂u/∂t|_ξ = (1/(cap·ξ·R²)) · ∂/∂ξ( ξ·cond·∂u/∂ξ )
```

其中 u=T（cap=ρcp、cond=k）或 u=C（cap=1、cond=D）；R(t) 由附件2 线性插值。

- **收缩仅通过 1/R² 加快扩散**（扩散路径变短），**不需要 R′=dR/dt**。
- **D=0 自检**：无扩散时每个物质点的 C 应守恒 ⇒ ∂C/∂t|_ξ=0，物质型满足；若按**空间型**（把题给固定-r 的 Eulerian 守恒式直接 front-fixing）会多出一项网格对流 (ξR′/R)·∂u/∂ξ，D=0 时仍产生**虚假平流** ⇒ 舍。本题 R′/R ~ 10⁻⁵/s 与扩散同量级，两口径差异显著，故取物质型为主口径（空间型留作敏感性对比）。

## 4. 数值方法

- **ξ 网格**：固定 N 点 ξ_i = i/(N−1) ∈ [0,1]（生产用 N=201，dξ=0.005，对应 R=2 cm 时物理间距 0.01 cm，细于 0.1 cm 输出分辨率）。
- **时间**：全隐式 backward-Euler，固定 dt=10 s（经 dt=5/10/20 验证时间步无关，见 §6）。
- **耦合**：每步 Picard 迭代联立 T、C（附录4 物性随 C 变、D 依赖 T(K) ⇒ 双向强耦合），容差 1e-8、上限 8 次。
- **算子复用**：ξ 系方程等价于**单位 ξ-圆盘上的径向扩散**，有效系数 cond/R²、有效对流 transfer/R。故直接复用问2/3 的守恒径向 FVM 隐式算子 `_implicit_radial_variable_step`，传入 dr=dξ、conductivity=cond/R²、boundary_transfer=transfer/R（radius_m=(N−1)·dξ=1）：
  - 中心 ξ=0：对称消 1/ξ 奇点（系数 4 技巧）；
  - 表面 ξ=1：第三类 Robin，−cond·∂u/∂ξ = transfer·R·(u_s−u_ext)；
  - 三对角 Thomas 求解。
- **R(t)**：每步由附件2 线性插值（`RadiusSeries.radius_cm_at`），t>72 h 取末值 1.198 cm（`np.interp` 自动 clamp）。
- **达标停机**：监测全剖面 max(C)，首次 <0.15 kg/kg 即停、记 t_end（中心 ξ=0 为最迟达标点）。
- **后期刚性**：D 随 C 减小呈指数衰减（e^(−0.30/C)：C=2.55→0.889、C=0.15→e^(−2)≈0.135），同时 R 收缩使 1/R² 增大（加快扩散），二者竞争；`moisture_diffusivity` 用 `maximum(C,1e-9)` 防除零、C 每步 `maximum(·,0)` 防负。

## 5. 输出口径（result4.xlsx / 表6）

- **result4.xlsx**：单工作表「水分浓度」，A 列=时间/s，其后为**固定距离列** 0,0.1,…,1.9 cm（数值表头，匹配模板）+ 末列**「药材表面」**；每 60 s 一行，末行为 t_end（烘干结束时刻，非 60 整数倍）。
- **表6**（`problem4_tables.md`）：每 6 h + 「烘干结束时间」行 × 距离 0,0.5,1.0,1.5 cm + 「药材表面」列。
- **Eulerian 固定距离取值**：固定距离 d 处 = C(ξ=d/R(t))，在 ξ 网格上线性插值；**「药材表面」= C(ξ=1)**（移动边界 R(t) 处）。
- **空值规则（关键）**：当固定距离 d > R(t)（材料已收缩过该点，该处无药材）⇒ 置**空**（Excel 空单元格）。故外层列（如 1.5–1.9 cm）在后期为空，呈三角空白区，忠实反映收缩前沿。经核验空白格与 d>R(t) **完全一致**（mismatch=0）。
  - 注：R(6 h)=1.374 cm <1.5，故表6 的 1.5 cm 列在 6 h 起全程为空；R 于约 36 h 渐近 1.200 cm。
- 所有数值保留 **4 位小数**（核验 43923 个数值格 not_4decimal=0）。
