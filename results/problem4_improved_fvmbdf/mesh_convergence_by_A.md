## 2. 收敛性判定 / Richardson / GCI

- **细网格相对变化**（401↔801）：|Δt\*|/t\* = 0.0083 / 50.7944 = **1.63e-4 < 1e-3** → 已达复核设定的收敛阈。
- **收敛形态**：ε₂₁=t\*(401)−t\*(201)=−0.0778 h，ε₃₂=t\*(801)−t\*(401)=+0.0083 h，**符号交替＝oscillatory convergence**；振幅比 |ε₂₁|/|ε₃₂|≈9.4（表观阶 p≈ln9.4/ln2≈3.2，因振荡仅供参考）。
- **Richardson 外推**（取 p=2、用 401/801）：t\*_ext ≈ 50.7944 + 0.0083/(2²−1) = **50.7972 h**。
- **GCI_fine**（Fs=1.25、p=2）：1.25 × 1.63e-4 = **0.020 %**，即 t\* = 50.794 h ± 0.010 h。
- **结论**：**L2 网格收敛 t\* ≈ 50.79 h**（生产口径取 xi=801 → **50.7944 h**，即本目录已提交的 `result4.xlsx` / `problem4_tables.md`）。201 点尚未收敛（比收敛值高约 0.07 h），故**不要用脚本默认的 xi=201 数字（50.8639h）作为论文定值**。
