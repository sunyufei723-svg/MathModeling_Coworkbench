**问1 模型骨架（据附录2 推导 · agent_A 初拟 2026-09-10T10:32Z，待 decisions.md 确认）**
- 域/坐标：一维径向柱坐标，r∈[0, R=0.02 m]、t∈[0,1800 s]；轴对称、忽略轴向（假设 B1）。
- 传热方程（ρ,cp,k 常数 → **线性**）：`∂T/∂t = α·(∂²T/∂r² + (1/r)·∂T/∂r)`，α=k/(ρ·cp)≈1.69×10⁻⁷ m²/s。
- 传质方程（D 随 C 变 → **非线性**扩散）：`∂C/∂t = (1/r)·∂/∂r( r·D(C)·∂C/∂r )`，D(C)=7×10⁻⁹·exp(−0.89·C)。
- **结构观察（重要）**：附录2 中 ρ/cp/k 常数、D 仅依赖 C ⇒ 问1 的 **T 场与 C 场数学上解耦**（可各自独立求解），比通用耦合假设 A1 简单；附录2 未给汽化潜热，倾向传热方程**不加蒸发源项**（纯导热）。是否引入潜热耦合项 → 待全队确认。
- 初始条件：T(r,0)=28 °C；C(r,0)=2.55 kg/kg（均匀）。
- 边界条件：
  - 中心 r=0（对称/无通量）：∂T/∂r=0、∂C/∂r=0。
  - 表面 r=R（第三类）：热 `-k·∂T/∂r|_R = h·(T(R,t) − T_env(t))`；质 `-D(C)·∂C/∂r|_R = hm·(C(R,t) − C_env(t))`；T_env/C_env 由附件1 插值。
- 数值方案（建议）：有限差分/有限体积离散；r=0 用对称性消 1/r 奇点（L'Hôpital → 2·∂²/∂r²）；显式须满足稳定性（取 Δr=0.1 cm、Δt=1 s 时热扩散数 α·Δt/Δr²≈0.17<0.5 稳定；传质 D 更小更稳），或用隐式/Crank–Nicolson；D(C) 非线性按当前步 C 更新或迭代；建议加密网格验证**网格无关性**。
- 单位：问1 中 T 用 °C 即可（无辐射、D 不依赖 T，边界只用温差）；长度 cm→m；问2/3/4 的 D 依赖 T(K) 时再换算绝对温度。

## 4. 关键假设
> 建模必须显式列出假设，后续在 decisions.md 确认。
> 下列假设由 **agent_A（2026-09-10T10:25Z）仅依据题干背景**（热风烘干；预热平衡+恒温干燥两阶段；调控烘房温湿环境；需数理分析与数值仿真求干燥规律）提出，目的是把物理过程理想化为**可数值求解的传热–传质耦合模型**；不依赖问题1–4 的具体数值，物性/经验公式待阅读问题与附录后套用。

**A. 过程本质（传热–传质耦合）**
- 假设 A1：烘干是**传热与传质耦合**过程——热风向药材供热（升温 + 供水汽化潜热），药材内部水分受热向表面迁移、在表面被气流带走；**温度场 T 与含水率场 C 相互耦合**，均随时间与空间变化。

**B. 几何与维度简化**
- 假设 B1：药材形状规则（近似圆柱），**长度远大于半径**，忽略轴向与端面效应，简化为**一维径向、轴对称**问题（状态量只沿"到中心距离 r"变化），把模型降为 1D 以便数值求解。

**C. 内部传递机理**
- 假设 C1：内部水分迁移以**扩散**为主，服从 **Fick 第二定律**，用**有效水分扩散系数 D** 刻画，D 随 C（及 T）变化。
- 假设 C2：内部热量传递以**热传导**为主，服从 **Fourier 定律**，用热导率 k 刻画；ρ、cp、k 等物性视为随 C/T 变化的经验量。
- 假设 C3：水分在内部的**汽化相变与潜热**作集总/简化处理（并入等效比热或源项），不显式追踪两相流动。

**D. 边界与外部环境**
- 假设 D1：药材表面与烘房热风间采用**第三类（对流/Robin）边界**——对流换热系数 h 描述表面换热、对流传质系数 hm 描述表面水分交换。
- 假设 D2：烘房温湿环境为**给定、可控的外边界**（按两阶段设定曲线变化）；烘房内空气温湿度均匀、风速稳定，忽略其空间不均匀性。
- 假设 D3：忽略**热辐射**换热与药材–托盘接触导热（常压热风干燥以对流为主）。

**E. 初始条件**
- 假设 E1：烘干初始时刻，药材**温度与含水率在空间上均匀分布**（取给定初值）。

**F. 阶段划分**
- 假设 F1：全程分**预热平衡**与**恒温干燥**两阶段——预热阶段以升温逼近烘房温度为主、水分变化相对小；恒温阶段温度趋稳、以持续脱水为主；两阶段边界条件与物性取值可不同，**分别建模再衔接**。

**G. 其它理想化**
- 假设 G1：**单根代表性药材独立干燥**，忽略药材间遮挡/堆叠对气流与温湿场的影响。
- 假设 G2：**干基质量守恒**，C = 水分质量 / 干物质质量；除脱水外忽略其它成分（如挥发油）质量损失。
- 假设 G3：物性参数与经验公式在适用范围内**连续、光滑**，便于离散与迭代求解。
- 假设 G4（可切换档位）：**尺寸/收缩**——一般先设药材尺寸不变（刚性）以简化；需精确刻画干燥后期或题目专门要求时，再引入随含水率变化的半径。
- 假设 G5（数值层面）：对时间/空间**离散**（有限差分/有限体积），物性随 C、T 更新，T 场与 C 场**耦合迭代**求解，并满足稳定性/收敛条件（扩散数、CFL 等）。

> **问1 特化（agent_A 2026-09-10T10:32Z）**：附录2 给问1 的 ρ/cp/k 为常数、D 仅依赖 C，故上述通用假设在问1 简化为「T 场与 C 场**解耦**、传热无蒸发源项」；尺寸固定，不启用 G4 收缩档位。详见 §2「问1 模型骨架」。
