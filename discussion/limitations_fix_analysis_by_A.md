## 一、问题四模型局限：干物质不闭合 28.02%（本轮重点）

### 1.1 现有表述与问题

`results/problem4_fvm_bdf/verification.json` 记录 `dry_mass_index_relative_range = 0.28017203887378966`，论文与结果说明均写作「题目给定 R(t) 和经验密度关系未形成严格质量闭合，是模型局限而非求解器失败」。这句话**方向正确但过于笼统**：没说清是哪两条关系冲突、冲突多大、能不能修、修了 t\* 会动多少。评委追问「那你为什么不用质量守恒的半径？」时无法回答。

### 1.2 代码级成因定位

**诊断量的定义**（`code/problem4_fvm_bdf/solver_bdf.py:230`）：

```
_dry_mass_index(R, C) = R² · Σ_i [ ρ(C_i)/(1+C_i) ] · V̂_i
```

其中 `ρ(C) = 760 + 90C`（`model.py:12`，附录 4 整体密度），`V̂_i` 是参考域 ξ∈[0,1] 的控制体体积（`fvm.py:28`，`Σ V̂_i = 0.5`），`R²` 是仿射收缩的雅可比因子。由于 C 是干基含水率（kg 水 / kg 干固），`ρ/(1+C)` 正是「单位整体体积中的干物质质量」，**这个诊断式本身在定义上是严格正确的**，不是代码写错。

**水分方程的实现**（`solver_bdf.py:137-175`）：

```
∂C/∂t|_ξ = (1/R²)·[ 内部 D 通量散度 + R·h_m·(C_ext − C_s) ] / V̂_i
```

方程中**不含任何密度因子**。这在物质坐标下是**正确的**水质量守恒形式，前提是「每个物质点的干物质质量守恒」，即仿射收缩下 ρ_s ∝ R⁻²。推导：取干物质线密度 m_s = ρ_{s0}R₀²∫dV̂ 为常数，则总水量

```
W = 2π ρ_{s0} R₀² ∫ C dV̂ ,   dW/dt = −2π ρ_{s0} R₀² h_m (C_s − C_ext)/R
```

而物理表面失水率 = 2πR·ρ_s(R,t)·h_m(C_s−C_ext)，代入 ρ_s(R,t)=ρ_{s0}R₀²/R² 后两式**完全相等**。代码的 `_normalized_balance_residual`（`solver_bdf.py:207`）检验的正是 `d/dt[Σ C_i V̂_i] = h_m(C_ext−C_s)/R`，实测残差 **2.087×10⁻¹⁶**。

**结论**：PDE、离散、诊断式三者各自都对。矛盾在于——**模型的水分平衡隐含要求 ρ_s = ρ_{s0}(R₀/R)²，而附录 4 的密度律给出的是 ρ_s = ρ(C)/(1+C)，这两条对同一时刻的干基密度给出不相容的数值。**

### 1.3 定量分解：κ = G × S

记 κ(t) = M_s(t)/M_s(0)（即代码的 dry_mass_index 归一化），可**精确**拆成两个因子：

```
κ(t) = G(t) · S(t),   G = (R(t)/R₀)²（几何/收缩）,   S = ⟨ρ_s(C)⟩_V(t) / ρ_s(C₀)（组成/密度律）
```

本轮以 N=401 独立复算（**t\* = 50.844229 h，与归档 `numerical_verification.md` 的 50.844229260 逐位一致**，故诊断可信）：

| ρ_s(0.15) / ρ_s(0.0525) | 672.6087 / 726.5796 | 干基密度随干燥**上升 2.4 倍** |

### 1.5 三条修复路径与定量代价

**路径 1 · 换密度口径（体积可加代替线性律）— 部分有效，零风险**

把干基密度从 `ρ_lin(C)/(1+C)` 换成 `1/(1/ρ_s + C/ρ_w)`（ρ_s=760 即附录 4 律在 C→0 的极限，ρ_w=1000）：

| 口径 | 全程 κ 变幅 | κ_min | κ(t\*) | 终点缺口 |
|---|---|---|---|---|
| A：附录 4 线性律 /(1+C)（现行） | 27.87% | 0.7198 @7 h | 0.8903 | **−10.97%** |
| B：体积可加，ρ_s=760, ρ_w=1000 | **21.33%** | 0.7857 @6 h | **0.9706** | **−2.94%** |

两条律在 C₀=2.55 处相差 7.75%（A 比 B 高），在 C=0.118 处只差 1.17%（A 比 B 低）——**说明附录 4 的线性式更像低含水率段的拟合，外推到初始 C=2.55 时最不可靠**。进一步二分标定：要使终点严格闭合，需 **ρ_s = 799.83 kg/m³（比 760 高 5.24%）**，此时 κ(t\*)=1.000000，**但 κ_min 仍为 0.7954 @6 h ⇒ 约 20% 的路径性漂移无法靠标定任何常数密度消除**。

→ **判定**：路径 1 能把终点缺口从 −11.0% 收到 −2.9%，能证明「题目数据在终点附近近乎自洽」，但**修不掉早期路径漂移**，因为它不是密度律的问题而是 R(t) 的问题。**推荐作为论文的一句加强论证，不改主模型。**

**路径 2 · 干物质闭合反解 R(t)（不动点迭代）— 有效但代价过大，只能当对照层**

令 R_{k+1}(t) = R₀/√(S_k(t))，即用上一轮模拟的组成因子强制干物质闭合，迭代求解：

| 迭代 | t\* / h（N=401） | κ 变幅 | R(t\*) / cm |
|---|---|---|---|
| iter0（附件 2 给定 R） | **50.844229** | 27.87% | 1.2000 |
| iter1 | 59.273071 | 6.85% | 1.2718 |
| iter2 | 60.503083 | 1.22% | 1.2718 |
| iter3 | **60.731240** | **0.17%** | 1.2718 |

闭合轨迹与给定轨迹的对照：t=1 h 时 1.9096 vs 1.7940，4 h 时 1.7170 vs 1.4770，12 h 时 1.4242 vs 1.2480 cm。

→ **判定**：闭合确实能把 28% 消灭到 0.17%（3 次迭代即收敛），**但 t\* 移动 +9.887 h（+19.45%）**。这个量级**远大于**边界情景的 ±3.3 h（47.68–54.28）和数值口径的 0.06%（L2→L3 差 0.030 h）。**因此绝不能用闭合分支替换题目给定的 R(t) 作主答案**——附件 2 是题设数据。它的正确用途是**第五层模型形式对照（L5）**，与已有的 L4（Euler 坐标 + 对流项，52.3842 h）同级，从而给出：

> **t\* 的模型形式区间 = [50.8245, 60.7312] h**，下界为题设给定收缩轨迹，上界为强制干物质闭合的自洽收缩轨迹。

**路径 3 · 在 PDE 里引入 ρ_s(C)（把 ρ_s C 作为守恒变量）— 不推荐**

把守恒变量从 C 换成 ρ_s(C)·C、通量换成 ρ_s(C)D∇C，看似"更严格"，但分析后无效：在物质坐标下每个物质元的干质量守恒要求 ρ_s ∝ R⁻²（纯运动学），而 ρ_s=ρ_s(C) 是本构关系，**两者只有在 R(t) 与 C(t) 满足闭合关系时才相容**——也就是说路径 3 并不消除矛盾，只是把同一个矛盾从"诊断指标"搬进"控制方程"，并且会与题设给定的 R(t) 直接冲突（等价于路径 2 的微分形式 dR/dt = −R·⟨ρ_s⟩′/(2⟨ρ_s⟩)）。**判定：不实施。**
