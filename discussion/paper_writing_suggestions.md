## 一、逐篇提炼

### 1. 2025-A196《多情形下无人机烟幕遮蔽策略的建模与优化研究》
- **文字风格**：摘要按「针对问题一/二/三/四/五」逐问分段；每段先一句建模思路、再给**加粗的最终数值+单位**（1.391643s、4.5873s、6.93586s、11.125936s、21.0770s）；关键词 5 个全为方法名（二分查找法/多起点变步长搜索/差分进化/分层次优化）。正文关键结论一律加粗。
- **语言结构**：顶层用中文数字「一、二、…」，子节 `x.y`/`x.y.z`；算法写成 `Step 1…Step N` 编号步骤而非伪代码图；公式独立成行、右对齐编号 `(5.1)`。
- **逻辑链路**：问题背景 → 问题提出（逐问列举）→ **图2 各问题关系图**（显化递进）→ 逐问「分析→建模→求解→结果展示→结果的分析与验证」→ 下一问开头用承接句（"问题二在问题一建立的数学模型基础上…"）。
- **图表插入位置**：图1 实景照片放**问题背景段内**；图2 关系流程图放**问题分析开头**总领；符号三线表紧跟模型假设；敏感性表/结果表放每问的「结果展示 / 结果的分析与验证」小节。
- **图表类型选择**：背景=实景照片；问题/变量关系=流程框图；几何推导=公式不配图；多参数方案=分组多级表头三线表（表5 投放/起爆坐标 X/Y/Z 跨列分组）；敏感性=横向对照表且**选定值加粗**（表3 不同 n 值）。

### 2. 2025-B060《红外干涉法测量外延层厚度的建模分析》
- **文字风格**：摘要分问题并**加粗方法名与结果值**（7.544μm / 7.295μm / 3.432μm / 7.455μm）；反复强调"交叉印证 / 相互验证"；关键词 4 个。
- **语言结构**：顶层用阿拉伯数字 `1 问题背景与重述 / 2 问题分析 / 3 模型假设`，带**页眉 running head**（左侧章名、右侧页码）；模型假设按物理对象分组（3.1 …）内用 (1)(2)。
- **逻辑链路**：每问给出**≥2 条独立求解路线**（周期波谷直接计算法 vs 牛顿迭代反演法）并互相验证；用统计指标（标准差、置信区间、变异系数 CV）评估可靠性。
- **图表插入位置**：数据曲线图（图4 滑动窗口样条+极值点标记）放**求解小节内、紧跟方法描述**；统计表放「厚度计算及结果」小节。
- **图表类型选择**：实测/拟合曲线=带图例折线+散点标记极值/异常点；统计汇总=三线表（统计量 × 入射角两列）；**异常值在表内加粗标注而非删除**（表1 标准偏差>3σ 标黑体）。

### 3. 2025-B157《碳化硅外延层厚度的双光束和多光束干涉法测量研究》
- **文字风格**：摘要分问题、**密集加粗物理定律与算法名**（Snell 定律、Fresnel 公式、Cauchy 色散模型、傅里叶变换、非对称最小二乘 AsLS、Savitzky–Golay、随机梯度下降）；给出精度量级（残差均方根 <1.14×10⁻³、幅值 <0.02）。
- **逻辑链路**：物理机理建模 → 数据预处理（等间距重采样/去趋势/去噪）→ 频域提取（滑窗 FFT 选有效带宽）→ 双角联合拟合 → **多维度可靠性检验**（残差统计、正态性、角度一致性、系统敏感性）。
- **图表类型选择**：光谱/残差类连续量=折线曲线图；预处理与频域选择=带标注的谱图；最终厚度=文内加粗数值。

### 4. 2025-C132《基于统计建模与元学习的 NIPT 检测决策优化与异常识别》
- **文字风格**：摘要分问题、加粗模型缩写与量化指标（LMM/REML、GPR、GA、MLP/LSTM/DeepHit、LightGBM+Optuna；AIC 提升 17.2%、94.7%、99.7%、误差<1.5%）；**问题背景段引真实文献**（Wang 等人 2013、Ashoor 等人 2012）作证据。
- **语言结构**：`一、问题重述`（1.1 背景 / 1.2 问题提出用 **bullet 列表**列问题一~四）。
- **逻辑链路**：相关性分析 → 混合效应模型 → 分层决策+风险最小化优化 → 生存分析/深度网络 → 堆叠集成；逐问从单一变量递进到多维异构特征。
- **图表插入位置**：背景段不插图、以文献证据立论；问题提出用 bullet；数据/模型类正文预期用流程框图+性能对比表。

### 5. 2025-C023《基于混合效应模型的 NIPT 时点优化与胎儿异常判定》
- **文字风格**：摘要分问题 + **末尾独立一段"本文创新性在于：一是…二是…三是…"**（三点创新）；加粗模型名与分组区间结果（[20.7,26.8]→11.9 周 等）；给拟合优度 R²=0.8962。
- **语言结构**：`一、问题重述`（1.1 背景带**上标数字引用** [1,2][2-4][5-7] / 1.2 问题要求逐问）。
- **逻辑链路**：机理示意图先行 → 相关性 → 混合效应 → 动态规划分组 → 多因素扩展 → 综合判定模型；交叉验证+灵敏度回验收尾。

## 二、跨论文共性规范（提炼）

### 2.1 摘要写法
1. 首段：背景一句 + 总方法/总框架一句。
2. 中段：**"针对问题一/二/…"逐问一段**；每段 = 方法（加粗模型/算法名）+ 关键结果（**加粗数值+单位**）。
3. 末段（可选）：验证/交叉印证一句，或"本文创新性在于：一是…二是…三是…"。
4. 关键词 4–6 个，优先方法/模型名。

### 2.2 章节骨架（两种主流，二选一并全文统一）
- 中文数字式：`一、问题重述 → 二、问题分析 → 三、模型假设 → 四、符号说明 → 五~…、问题X模型建立及求解 → 模型检验/评价 → 参考文献 → 附件`。
- 阿拉伯式：`1 问题背景与重述 → 2 问题分析 → 3 模型假设 → 4 符号说明 → 5 模型建立与求解 → …`，可加页眉 running head。
- 可单列的加分小节：**名词解释与变量说明、数据预处理、显著性/可靠性检验、模型优缺点**。

### 2.3 逻辑链路
- 问题重述后**紧跟一张"各问题关系图/逻辑框图"**，显化问与问的递进与复用。
- 每问内部固定闭环：**分析 → 假设 → 建模 → 求解 → 结果展示 → 验证/敏感性**。
- 问与问之间用**承接句**（"在问题X建立的模型基础上…"）。
- **多方法交叉验证**（直接法 vs 迭代法、解析 vs 数值、处理前 vs 后）是国奖高频加分点。

### 2.4 图表插入位置规律
| 图/表 | 插入位置 |
|---|---|
| 实景照片 / 彩色机理示意图 | 问题背景段内（建立图景） |
| 问题关系图 / 变量逻辑框图 | 问题分析开头（总领） |
| 几何 / 受力 / 坐标示意图 | 建模小节、紧跟对应公式 |
| 数据曲线 / 拟合图 | 求解或结果小节 |
| 结果表 / 敏感性表 / 多工况对照表 | "结果展示 / 分析与验证"小节 |
| 处理前后对照图 | 检验 / 降噪 / 优化效果小节 |
| 符号说明三线表 | 模型假设之后 |

### 2.5 图表类型选择（按上下文）
- 讲背景/机理 → 照片或彩色机理流程图。
- 讲问题间/变量间关系 → 框图 / 流程图 / 逻辑图。
- 讲几何/受力/坐标 → 矢量示意图（标注符号）。
- 讲连续量随参数变化 → 折线/曲线图（带图例，标记极值/异常点）。
- 讲多工况/多方法对比 → 分组三线表或并排子图。
- 讲统计可靠性 → 统计量表（均值/标准差/CI/CV）。
- 讲图像/重建/降噪效果 → 处理前后成对图。
- 讲离散方案/参数/标定值 → 三线表（**选定值加粗**）。
- 结果体量过大 → 正文放代表值+图，**全量写附件 xlsx**。

### 2.6 表格规范
三线表（booktabs 风格）；表头带单位；多级表头用跨列分组；长表加"续下页"；**关键/选定值加粗**；异常值加粗标注而非删除。

### 2.7 语言与证据
客观陈述为主、叙述章适度第一人称"我们"；关键结论与数值加粗；方法/模型首次出现给全称+缩写；背景段引**真实可核验文献**；表述强度与证据匹配（有检验才写"验证/表明"，推断写"说明/提示"）。

## 三、对本仓库论文（files/final/A题完整论文.tex）的可执行建议
1. **加一张"四问关系/递进复用图"**（框图）放在问题分析或问题重述后：显化 Q1→Q2→Q3→Q4 复用同一守恒径向 FVM+BDF 算子、逐问放宽假设的递进链。

4. **敏感性/UQ 用统计量表或条形图**：Morris μ*、Sobol S_i/S_Ti 用对照表/条形图呈现，而非纯文字；标注"条件工程扰动、非统计 CI"。
5. **符号表保持三线表+续下页**；结果表选定值加粗。
6. **背景/物性/数值格式补真实文献引用**（符合 docs/6 质量规则）；叙述章保持"我们"人称。
7. 摘要已分问题且四位小数，**保持**；可在每问末确认主值加粗。
