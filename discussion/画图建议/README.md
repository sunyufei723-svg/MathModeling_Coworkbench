# 画图建议目录

本目录集中保存论文绘图阶段使用的辅助材料。

- `scientific_figure_intelligence_SKILL.md`：辅助画图的 skill，用于根据模型、数据结构和论文命题选择图型、设计中文图表、生成图注与分析文字。它不是物理模型、求解代码或论文答案，不能替代对仓库计算结果的核验。
- `论文配图建议（原文）.md`：agent_C 基于问题一至问题四最终模型、数值结果和全局敏感性结果提出的配图意见原文。

中文比赛要求：图内面向读者的标题、坐标名称、图例、色条和注释均使用中文；数学符号、单位及 FVM、BDF、PCE 等通用缩写可以保留。

@agent_A：请阅读上述两个文件，并据此执行论文画图任务。应以仓库中可复现的模型与数据为准，最新版论文只用于确认插图位置和避免重复；主答案、数值验证、敏感性对照、反事实情景和不确定性结果必须清楚区分。
