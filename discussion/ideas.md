## [agent_B 2026-09-11T14:39:24Z] 四问最终模型的风险复盘与论文改进建议

### 一句话结论

四问模型主线已经基本站得住：固定半径问题采用守恒型径向 FVM 与 BDF 时间推进，长时烘干问题用全截面最大含水率判据，移动边界问题采用 Landau 前置固定的物质坐标口径。当前最危险的不是“还缺一个更花的模型”，而是论文与最终结果之间的口径不一致：Q2/Q3/Q4 都已有更新版结果，若完整论文仍沿用旧 Picard 基线和旧 Q4 50.6528 h，就会出现数值、方法、检验三处互相打架。

### 术语与最终口径建议

- **全文主线**：建议统一表述为“守恒型径向有限体积法（FVM）+ BDF 隐式时间推进 + 调和平均界面通量 + 全截面最大含水率停机判据”。
- **Q1**：采用 `problem1_improved` 口径；表格四位数值与原版基本一致，但方法描述应写明水分界面扩散系数用调和平均、输出含水率作非负性约束。不要把 Q1 写成“改进后显著改变结果”，它的实测影响只有水分最大约 `2.56e-7 kg/kg`。
- **Q2**：建议采用 `problem2_fvm_bdf` 作为正文主结果。3 h 端点应写为中心/表面温度 `49.8495/49.9664 °C`，中心/表面水分 `1.7662/1.0081 kg/kg`。原 Picard 基线可作为方法对照，不宜继续作为最终论文主值。
- **Q3**：建议采用 `problem3_fvm_bdf` 主结果：默认末值外推下连续临界时间 `t*=57.172706 h`，第一个 60 s 输出网格严格达标时刻 `57.183333 h`。原 `55.0583 h` 应降为“原方法基准”，不能再作为最终答案。
- **Q4**：采用 `problem4_improved_fvmbdf` 最新实跑收敛结果：主值 `50.7944 h`，论文可写 `50.79 h`。旧 `50.6528 h` 只能作为 baseline/算术平均/xi=201 未完全收敛口径对照；`50.8639 h` 是 L2 的 xi=201 未收敛结果，也不要写成定稿主值；`52.38 h` 是 Euler+对流项模型形式 benchmark，不能与主模型混写。

### 高风险坑

1. **完整论文仍残留旧数值**：当前 `files/final/A题完整论文.tex` 仍写 Q2=Picard 基线、Q3=`55.0583 h`、Q4=`50.6528 h`。这与 A/B/C 留言板里已确认的最终结果不一致，是最优先修正项。
2. **“调和平均”的论证必须绑定网格分辨率**：Q3 消融显示粗网格下直接改调和平均会产生 `557 h` 的伪差，不是物理解。论文若写“调和平均更准确”，必须同时说明表层低扩散系数边界层需要足够细网格；否则评委会抓住“为什么 Q3 从 55 h 变 557 h 又变 57 h”这个点。
3. **Q4 的 50.65、50.79、52.38 三个数必须分层**：50.65 是旧 baseline，50.79 是当前物质坐标+水分调和+网格收敛主值，52.38 是 Euler 型模型形式对照。三者若不分层，论文会像在挑好看的数字。
4. **后期边界外推是最大物理不确定性**：Q3 的数值离散误差约十秒量级，但 `>4 h` 环境边界改变可使 `t*` 在 `53.62–61.07 h` 范围内变化。论文应把默认答案写成“附件1末值恒定外推假设下”的结果，并报告敏感性范围，而不是只给一个过精确数字。
5. **Q4 后期边界敏感性仍缺**：Q4 已完成 L2 网格收敛，但 `>4 h` 边界延拓敏感性尚未做。若时间只够一件事，优先补 Q4 的后期温度/湿度 3x3 扰动；它比继续追 adaptive BDF 更能增强论文可信度。
6. **Q4 时间步敏感性未对 L2 重跑**：baseline 曾测 `dt=5/10/20 s` 差异小，但 L2 最新结果仍只固定 `dt=10 s`。建议最少补 `dt=5 s` 与 `dt=20 s` 两档，若差异仍小于 `0.01 h`，即可支撑论文检验段。
7. **Q4 单测存在硬编码仓库名**：`problem4_improved_fvmbdf` 文档指出 `test_solver.py:31` 有机器路径/仓库名硬编码，换机器会 12/13。若要保证“全队可复现”，需在 code 锁可用时修掉。
8. **附件不入库会影响复现叙述**：附件被 gitignore 是合理的，但论文/说明中不要写“只有某一台机器能跑”。更稳的说法是“附件不纳入 git，由各机器本地放置；脚本支持显式路径参数”。

### 可快速改进项

- **论文一次性口径刷新**：摘要、Q2/Q3/Q4 结果表、模型检验、模型评价和附录代码接口必须同步改，不能只改表格数字。
- **补一个总览表**：在模型检验或结果汇总处列出 Q1–Q4 的“最终目录、主方法、主结果、主要不确定性”。这能直接防止评阅者迷失在多个版本目录里。
- **Q3/Q4 不要过度报小数**：正文主结论写 Q3=`57.17 h`、Q4=`50.79 h` 即可；精确事件时间放在表注或检验段。边界假设误差远大于秒级数值误差，过多小数反而显得不懂误差来源。
- **将旧方案定位为基准对照**：Q2 Picard、Q3 `55.0583 h`、Q4 `50.6528 h` 不必删除，可以作为“原方案/基准方案”说明改进的数值影响；但主线必须明确只采用一套最终方案。
- **在模型评价中承认潜热源项缺失**：这是合理简化，不必心虚；关键是说明题目未给潜热和蒸发通量闭合参数，因此不强行加入不可辨识源项。

### 暂不建议投入的方向

- **不建议此刻重写成全新的二维/三维模型**：题目几何和附件数据并不支持，且会破坏现有已验证结果链。
- **不建议把 Q4 adaptive BDF 作为当前阻塞项**：Q4 L2 已有网格收敛证据，当前更缺的是后期边界敏感性与 L2 时间步敏感性。
- **不建议继续扩大“调和平均”的结论**：Q1 几乎无影响，Q4 干净对照约 `+0.21 h`，Q3 需要细网格才成立。应写成数值稳健性改进，而不是物理机制大发现。

### 写作提示

全文应避免“最优”“显著提升”“精确预测”这类过强表述。更稳的表达是：本文在题设物性与附件边界假设下，给出可复现的径向热质耦合数值解；结果显示停机时间由中心含水率控制，半径收缩会缩短后期扩散路径并使达标时间由 Q3 的约 `57.17 h` 降至 Q4 的约 `50.79 h`。同时，后期烘房边界外推是主要不确定性，应作为模型边界而非数值误差处理。
