### 一句话结论
现有主干（守恒径向 FVM + 隐式 BDF + 调和平均界面 + Landau 物质坐标 front-fixing）对本题已**恰当且可辩护**；「换个更花的物理模型」收益低（多缺参数、不可辨识）。**真正增益在三处**：①**验证与不确定度**（解析交叉验证 + MMS + Sobol/MC-PCE，把 t\* 从点估计升为带置信区间的可信结论，直击 B 的头号不确定项 >4h 边界）；②**后期刚性/强耦合的求解**（Newton、Radau IIA 替代/交叉 Picard+BDF1）；③**Q4 移动边界口径完备性**（物质型 front-fixing 已对，补 ALE 定位 + 与附件2 R(t) 的质量守恒一致性校验）。

### 1. 物理模型层面（多为「更物理但参数不可辨识」→ 讨论/展望，非主模型）
- **Luikov 热质耦合（毛细多孔体干燥经典模型）**：现水分通量仅 Fick 项 J=−D∇C；Luikov 加**温度梯度驱动项** J=−D∇C−Dδ∇T（热质交叉效应）。热风干燥内部 T 梯度大时物理上非零。**但 δ 附录未给→不可辨识**，强加=引入自由参数。→ 仅讨论/展望（同 B 对潜热的处理逻辑）。
- **汽化潜热源项**：现传热无蒸发汇（附录未给潜热 L）；恒温段蒸发强，缺此项→T 偏高→D(C,T) 偏大→t_end 偏短。最省辨识的纳入法是**视比热法**（把 L 摊进 cp 的湿分区间），但 L 与蒸发闭合仍缺→仍不可辨识。→ 维持 B「承认为合理简化」，补一句「若给定 L 可用视 cp 法纳入」。
- **两相/多相多孔介质（Whitaker 体积平均 / Philip–de Vries）**：气-液-固三相 + 毛细压力 + 相对渗透 + 蒸发冷凝，最完备；**需孔隙率/渗透率/毛细曲线/吸附等温线一大堆参数，题目全未给→严重过度工程**，且推翻现有已验证结果链。→ 不建议。
- **非 Fickian / 分数阶扩散**：低湿分异质生物介质或有记忆/亚扩散；**但题设 assumption C1 明确 Fick 第二定律、无数据辨识阶数 α**→与题设冲突、不可辨识。→ 仅展望。
- **收缩本构（Q4）**：R(t) 是**附件2 给定数据**、非求解量，物质坐标 ξ=r/R(t) 已假设均匀缩放→**不需升级收缩模型**。但值得一个低成本**一致性校验**：把算得脱水量（∫C 变化）与附件2 的 R(t)²（干基体积）做质量守恒对照，验证「均匀缩放」自洽、增强 Q4 可辩护性。

### 2. 数值方法层面
**时间推进**（现：BDF1 固定 dt=Q4 L2 / 自适应 BDF=C 的 L3、Q2/Q3 改进）
- **隐式 Runge–Kutta（Radau IIA，L-稳定 3/5 阶）**：Arrhenius 刚性 + 强耦合的金标准，比 BDF1 更准更稳、自带嵌入误差控制（`scipy.solve_ivp(method='Radau')`）。→ **值得作 Q3/Q4 后期刚性的交叉验证档**（与 C 的 adaptive BDF 并列看 t\* 是否一致）。
- **Crank–Nicolson（2 阶 A-稳定）**：精度更高，但对尖锐前沿/刚性衰减**会振荡**（非 L-稳定），需 Rannacher 启动（头几步 BE）。→ dt 敏感性本已小、增益边际、有振荡风险，**中低优先**。
- **指数积分器 ETD / Rosenbrock**：线性扩散部分用矩阵指数精确处理→大步长无稳定限制；Rosenbrock 每步一次线性求解更省。→ 优雅但实现成本高，竞赛**不建议**。

**非线性耦合**（现：Picard 逐次迭代）
- **Newton 全联立（对 T–C 系统）**：二次收敛，后期强耦合（D 对 T 指数敏感）时比 Picard 少迭代、不易 stall。C 的自适应 BDF 内部已用 Newton→**改进版已隐含此升级**；若保留固定步 Picard 生产档，可换 Newton 提稳健性。→ **推荐**（尤其后期）。
- **Anderson 加速 Picard**：不换 Newton 也能低成本加速定点收敛（存几步历史、免 Jacobian）。→ 便宜的稳健性补丁。
- **算子分裂（Strang 热/质）**：子问题更简单但强耦合引入分裂误差。→ 不推荐主用，可作耦合误差量化对照。

**空间离散**
- **谱方法（Chebyshev 配点）**：1D 径向光滑问题指数收敛→极少点数达高精度，是**验证 FVM 的近精确参照**；Q1/Q2 早期光滑段尤佳，Q3/Q4 后期陡边界层优势下降。→ **作交叉验证档推荐**（非生产求解器）。
- **有限元（Galerkin 二次元 + ALE）**：变系数 + Robin + 移动网格天然，对 Q4 提供 front-fixing 之外的 ALE 路子；与本 1D 问题同阶，主要价值在 Q4 ALE，**中等**。
- **分级/自适应网格（表层加密）**：点集中在 ξ→1 陡边界层；网格收敛已达（GCI 0.02%）→精度增益边际、主要省算力，**低优先**。

**移动边界（Q4）**（现：Landau 物质坐标 front-fixing、无对流项、D=0 自检已验证）
- **ALE 移动网格**：网格随边界速度移动，是 front-fixing 的一般化；均匀缩放下二者等价。→ 作「我们的 front-fixing 是 ALE 特例」的理论定位，增强严谨性，非必须换。
- **Stefan / 焓法**：适用于**自由边界**（前沿位置是解的一部分）；本题 R(t) 是**给定数据、非自由边界→不适用**。但论文宜点明「为何不用 Stefan」（前沿由附件2 prescribed），预防评委追问。
- **Eulerian 空间坐标 + 对流项**：即 L4 作者 benchmark（52.38h）→已有，作模型形式敏感性对照（物质型 vs 空间型）。

### 3. 验证与不确定度（V&V / UQ）——本题增益最大处
- **解析/半解析交叉验证（低成本高价值）**：
  - **Q1 温度场 Bessel 本征函数级数解**：Q1 ρ/cp/k 常数→热方程**线性**，径向 Robin BC 有经典 Bessel 级数解析解→**近精确验证 FVM 温度算子**（Q2/Q3/Q4 复用同一空间算子→一并背书）。→ **强烈推荐**（rigorous、零风险、评委信服）。
  - **早期半无限相似解（erfc/Boltzmann）+ 穿透深度 δ~√(αt)**：早期表层≈半无限介质，校核早期表面行为（problem.md §7 已有量级：1800s 热 1.74cm/水 0.30cm）→便宜的 sanity envelope。
- **制造解法 MMS（代码验证）**：GCI/Richardson（已做）验**收敛性**、不验**正确性**；MMS 造已知解析 C/T、反推源项、跑求解器看是否按预期阶数复原→**证明代码正确**。→ **推荐至少对一问做**（回答「你怎么知道 FVM 没错」）。
- **全局敏感性（Sobol 方差分解 / Morris 筛选）**：对 t\* 关于 {>4h 恒温 T_env/C_env、h、hm、D 前因子、活化能 3850} 求 Sobol 指数→**量化排序**哪个假设主导 t\* 方差，直击 B 头号不确定项。先 Morris 粗筛再 Sobol 精算。→ **最高价值/低成本，强烈推荐**。
- **不确定度量化（LHS 蒙特卡洛 / 多项式混沌 PCE）**：把 >4h 边界(+h/hm)当不确定参数传播→ t\* 给**置信区间**（如 57.2 [53.6,61.1] h @95%），兑现 B「不要过度报小数」。低维(2-3 参数)用 **PCE** 建代理→解析得均值/方差/Sobol，比 MC 省。→ **强烈推荐**（点估计升为带 CI 结论）。
- **降阶模型 ROM（POD-Galerkin）/ 集总参数模型**：Sobol/MC 要跑成百上千次长积分很贵；对湿分场做 POD 得低阶基、或建 surface+center 两节点集总 ODE（标定到全 PDE）→敏感性循环提速 100–1000×，并给「t_end 由中心湿分控制」的解析洞见。→ **UQ 使能器**，中等价值（有实现成本）。
- **代理 / 高斯过程 GP**：2-3 参数、~50 次 PDE 跑训 GP→免费给概率 t\*。仅在做大规模 UQ 时用；Sobol/PCE 对竞赛更标准可辩护，**勿为 ML 而 ML**（呼应 B 反过度工程）。
- **诚实前提**：本题是**给定参数的前向仿真、无实验数据可拟合**→做不了数据驱动模型选择（AIC/BIC/CV），也拿不到数据校准 D；模型取舍只能靠**物理推理 + V&V + UQ**。这点要在论文讲清，预防评委问「为何不拿数据校准」。

### 4. 分问速配
- **Q1（解耦·温和·线性热）**：Bessel 级数解析解 + Chebyshev 配点→近精确交叉验证温度算子（背书全链）。
- **Q2（强双向耦合·3h）**：Newton 全联立 vs Picard（量化迭代收益）；Radau IIA 自适应；算子分裂对照估耦合误差。
- **Q3（长时间·达标停机·刚性）**：Sobol/MC-PCE 给 t\* 置信区间；POD-ROM/集总模型跑敏感性循环；Rannacher-CN vs BDF 校时间误差。

### 二、已完成内容的主要不足

#### 1. Bessel与MMS验证范围比名称看起来窄

目前能够证明的是：

\[
\boxed{\text{内部径向FVM空间算子约为二阶收敛}}
\]

还不能直接证明：

\[
\boxed{\text{整套热湿耦合、Robin边界、BDF事件求解器均为二阶}}
\]

具体而言：

- Bessel测试采用Dirichlet特征模态，不是问题一实际的对流边界；
- MMS未验证最外层半控制体；
- 两者都没有覆盖时间积分；
- 没有覆盖问题二、三的变物性耦合；
- 没有覆盖问题四移动坐标中的收缩项。

因此论文中应写“验证径向FVM内部空间算子的二阶收敛”，不宜扩大为“验证了完整模型的二阶收敛”。

#### 2. LHS的5000个样本并不等于5000次高保真计算

实际信息来源仍是 \(3\times3\) 共9个边界情景，5000个LHS样本是在双线性代理上计算的。因此：

\[
48.1038\sim53.8402\rm\,h
\]

只能称为：

> 在给定均匀分布和边界扰动范围下的代理抽样区间。

不能称为：

- 95%统计置信区间；
- 总体预测区间；
- 覆盖全部模型不确定性的范围。

目前还缺少若干代理外验证点，用来检查双线性插值在参数空间中的误差。

#### 3. 质量闭合问题已经查明，但替代模型尚未正式交付

现在已经较有力地确认：

- 28.02%的质量指标偏差不是离散守恒误差；
- 网格从N401加密到N3201后几乎不变；
- 附件4给出的体积收缩和密度关系无法同时维持干物质质量闭合；
- 潜热不会消除这个矛盾，反而可能延迟干燥。

但是 \(60.7312\rm\,h\) 仍只是N401临时计算值。正式采用它至少还需要：

- 独立代码目录；
- N3201生产计算；
- 网格与时间敏感性；
- 与当前主模型的同口径比较；
- 测试、文档和结果文件。

所以当前仍应保持：

\[
\boxed{50.8245\rm\,h\text{是题设直接模型答案}}
\]

\[
\boxed{60.7312\rm\,h\text{只能是待正式验证的质量闭合情景}}
\]

价值：中等；可执行性：中等。

相比继续增加新的数值求解器，更建议补齐当前MMS/Bessel最大的缺口：

- 验证外层半控制体；

#### P5：Radau交叉验证

价值：中等偏低；可执行性：较高。

#### P6：PCE、移动域MMS和求解器加速

价值：低到中等；可执行性：中低。

建议顺序为：

1. 只有在现有双线性代理验证不通过时才做PCE；
